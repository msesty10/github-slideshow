Jak pracuju

Začínám rozhovorem o tom, co má web zákazníkům usnadnit. Teprve potom kreslím a programuju.

Weby jsou rychlé, čitelné na malém telefonu a jdou je upravovat bez programátora. Po spuštění zůstávám po ruce, když je potřeba něco změnit.

Návrh a prototyp

Struktura stránek, texty a vzhled. Prototyp si můžete proklikat dřív, než se začne programovat.

Vývoj

HTML, CSS a JavaScript bez zbytečných závislostí. Web se načte rychle i na slabším připojení.

Správa po spuštění

Drobné úpravy, zálohy a aktualizace za pevnou měsíční cenu.
